# Django Setup Notes

## 1. Environment (Virtual Environment)

### Step 1 — Create a Virtual Environment

Project folder ke andar ye command run karo:

```powershell
python -m venv venv
```

Yahan:

* `python` → Python ko run karta hai
* `-m venv` → Python ka virtual environment module
* `venv` → Environment ka naam

### If `python -m venv venv` does not work

Pehle incomplete `venv` folder remove karo:

```powershell
Remove-Item -Recurse -Force .\venv
```

Then:

```powershell
python -m ensurepip --upgrade
```

Check pip:

```powershell
python -m pip --version
```

Uske baad dobara:

```powershell
python -m venv venv
```

---

### Step 2 — Activate the Virtual Environment

Virtual environment activate karne ke liye:

```powershell
venv\Scripts\activate
```

PowerShell mein recommended command:

```powershell
.\venv\Scripts\Activate.ps1
```

Agar successfully activate ho gaya, terminal mein:

```text
(venv) PS C:\Users\amant\Desktop\Django\YourProject>
```

`(venv)` दिखाई देगा.

---

### Step 3 — Check Django Installation

Pehle check karo Django already installed hai ya nahi:

```powershell
python -m django --version
```

Agar Django installed nahi hai, install karo:

```powershell
pip install django
```

Better/recommended:

```powershell
python -m pip install django
```

---

### Step 4 — Verify Django Installation

Django install hone ke baad:

```powershell
python -m django --version
```

Example:

```text
6.1
```

Agar version show ho raha hai, Django successfully install ho gaya hai.

---

# 2. Django Project

## Step 1 — Start a Django Project

Virtual environment activate hone ke baad:

```powershell
django-admin startproject YourProjectName .
```

Example:

```powershell
django-admin startproject myproject .
```

### Important

Command ke end mein `.` (dot) important hai.

```text
django-admin startproject myproject .
                                             ↑
                                      Current folder
```

Isse `manage.py` current folder mein create hoga.

Project structure approximately:

```text
YourProject/
│
├── venv/
│
├── manage.py
│
└── myproject/
    ├── __init__.py
    ├── settings.py
    ├── urls.py
    ├── asgi.py
    └── wsgi.py
```

---

# 3. Django App

## Step 1 — Create an App

Project ke folder mein, jahan `manage.py` hai:

```powershell
python manage.py startapp YourAppName
```

Example:

```powershell
python manage.py startapp invoices
```

App structure:

```text
invoices/
│
├── migrations/
├── __init__.py
├── admin.py
├── apps.py
├── models.py
├── tests.py
└── views.py
```

---

## Step 2 — Add App to `settings.py`

Apne **project folder** ke andar:

```text
myproject/
└── settings.py
```

`settings.py` open karo.

`INSTALLED_APPS` ke andar apne app ka naam add karo:

```python
INSTALLED_APPS = [
    "django.contrib.admin",
    "django.contrib.auth",
    "django.contrib.contenttypes",
    "django.contrib.sessions",
    "django.contrib.messages",
    "django.contrib.staticfiles",

    "invoices",
]
```

Yahan:

```python
"invoices",
```

tumhare app ka naam hai.

Agar app ka naam `billing` hai:

```python
"billing",
```

Agar app ka naam `accounts` hai:

```python
"accounts",
```

---

# 4. Run Django Server

Project ke root folder mein jao, jahan `manage.py` hai:

```powershell
python manage.py runserver
```

Successful output kuch aisa hoga:

```text
Starting development server at http://127.0.0.1:8000/
```

Browser mein open karo:

```text
http://127.0.0.1:8000/
```

---

# Complete Flow

Django project banane ka basic flow:

```text
1. Create Environment
       ↓
python -m venv venv

2. Activate Environment
       ↓
.\venv\Scripts\Activate.ps1

3. Install Django
       ↓
python -m pip install django

4. Check Django
       ↓
python -m django --version

5. Create Project
       ↓
django-admin startproject myproject .

6. Create App
       ↓
python manage.py startapp invoices

7. Add App in settings.py
       ↓
"invoices",

8. Run Server
       ↓
python manage.py runserver
```

## Remember These 5 Commands

```powershell
# Create environment
python -m venv venv

# Activate environment
.\venv\Scripts\Activate.ps1

# Install Django
python -m pip install django

# Create project
django-admin startproject myproject .

# Create app
python manage.py startapp invoices
```
